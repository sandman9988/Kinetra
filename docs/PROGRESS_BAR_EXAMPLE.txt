STATUS CATEGORIES EXPLAINED:
────────────────────────────────────────────────────────────────────────────

✅ DOWNLOADED
   - Successfully downloaded ≥100 bars
   - Data saved to file
   - Ready for training

⏭️ UP TO DATE
   - Existing file is current (within 24h)
   - No download needed
   - Skip to save API quota

⚠️ SKIPPED (No Data)
   - 0 bars available from broker
   - Symbol may not exist on this broker
   - OR insufficient history (< 100 bars)
   - Soft-block: other downloads continue

❌ FAILED (Error)
   - Network error, timeout, or exception
   - After all retries exhausted
   - Check logs for details


RETRY BEHAVIOR:
────────────────────────────────────────────────────────────────────────────

Symbol-Level: Up to 3 attempts
  Attempt 1 → 0 bars → Wait 2s
  Attempt 2 → 0 bars → Wait 2s  
  Attempt 3 → 0 bars → SKIP

Chunk-Level: Up to 5 attempts per chunk
  Rate limit → Exponential backoff: 1s, 2s, 4s, 8s, 16s
  Network error → Retry with backoff
  Success → Continue

Empty Chunk Detection:
  3 consecutive empty chunks → STOP (end of data)


WHAT "0 BARS" MEANS:
────────────────────────────────────────────────────────────────────────────

Scenario 1: Symbol not offered by broker
  Example: BCHJPY on Vantage
  Result: SKIPPED
  Reason: "No data available from broker"

Scenario 2: Already up to date
  Example: Downloaded yesterday
  Result: UP_TO_DATE
  Reason: "No new data (existing: 5000 bars)"

Scenario 3: Temporary broker issue
  Result: RETRY up to 3 times
  If still 0 → SKIPPED

Scenario 4: Symbol name mismatch
  Example: BTCUSD vs BTCUSD+ vs BTCUSD.m
  Result: Auto-discover correct suffix
  If not found → SKIPPED
