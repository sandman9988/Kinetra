================================================================================
                    🧹 REMOVE PLACEHOLDER SETUP
================================================================================

PROBLEM: Environment variables with placeholder values are overriding your
         .env file credentials.

FIX: Choose ONE option below:

================================================================================
OPTION 1: Quick Fix (Current Terminal Only)
================================================================================

Run this command:

    source scripts/unset_placeholders_now.sh

This unsets the placeholders immediately in your current terminal.

================================================================================
OPTION 2: Manual Unset
================================================================================

Copy and paste these two lines:

    unset METAAPI_TOKEN
    unset METAAPI_ACCOUNT_ID

================================================================================
OPTION 3: New Terminal (Cleanest)
================================================================================

Simply:
    1. Close this terminal window
    2. Open a new terminal
    3. Navigate back to the project

The placeholders won't exist in the new terminal since they're not in
your ~/.bashrc or other config files (we already checked).

================================================================================
VERIFY THE FIX
================================================================================

After using any option above, verify it worked:

    env | grep -i metaapi

Expected: No output (clean) OR real values from .env file

Then test the connection:

    python scripts/download/test_metaapi_connection.py

Expected: ✅ CONNECTION TEST PASSED

================================================================================
WHY THIS HAPPENED
================================================================================

Something in this terminal session set these placeholder values:
    export METAAPI_TOKEN=your-token-here
    export METAAPI_ACCOUNT_ID=your-account-id-here

They're only in THIS terminal session (not in config files).

Your .env file has the REAL, WORKING credentials - we tested them!

================================================================================
RECOMMENDATION
================================================================================

Use OPTION 3 (new terminal) - it's the cleanest solution.

All your scripts will then automatically use the real credentials from
the .env file.
